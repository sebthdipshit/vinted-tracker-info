Vinted Tracker

A private desktop tool that reads Vinted sales emails in Gmail with read-only access and calculates sales revenue locally on the user's own Mac.

Private, non-commercial tool. Vinted Tracker is not a public service and is not offered to other users. It is used only by its developer with the developer's own Gmail accounts. It is not affiliated with, endorsed by or sponsored by Vinted or Google.

What it does

Reads Vinted emails

Searches the connected Gmail account for messages from Vinted, such as "item sold" and "order completed" notifications.

Recognises sales

Extracts the transaction ID, item name, date and amounts using fixed, explicit rules. Unclear emails are marked for manual review.

Shows revenue locally

Stores the results in a local database and shows revenue and sales in a dashboard that runs only on the same computer.

How it uses Google data

  • Read-only Gmail access (gmail.readonly). The app cannot send, delete or change emails.
  • Optional profile picture (openid, userinfo.profile). Requested only if the user opts in, to show the account's picture in the local dashboard.
  • Everything stays on the computer. There is no server, no cloud storage, no analytics and no advertising. Data is never sold or shared.
  • Sign-in happens at Google. The app never sees or stores the Gmail password. Sign-in tokens are kept in the macOS Keychain.
  • Access can be revoked at any time from the app or at myaccount.google.com/permissions.

Full details: Privacy Policy.

Technical overview

  • Runs locally on macOS (Python and a local Next.js dashboard bound to 127.0.0.1).
  • Uses a Google OAuth client of the type "Desktop app" with a loopback (localhost) redirect.
  • Several Gmail accounts can be connected. Each signs in separately.
